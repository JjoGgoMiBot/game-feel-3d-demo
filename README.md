# 전투 아레나 — 손맛(game-feel) 3D 데모

3D 아레나에서 적 4마리와 싸우며 맞는 순간의 연출을 직접 느껴 보는 데모. 설치 없이 `index.html`만 열면 된다(정적 파일, 빌드 없음).

- 이동: WASD / 방향키 · 공격: 스페이스 또는 화면 클릭 · 휴대폰은 화면 위 방향 버튼과 공격 버튼
- 맞을 때마다 일어나는 것: 히트스톱(게임 시간 정지) · 카메라 흔들림 · 줌 잠금 · 앞쪽 적으로 살짝 끌려가는 공격 흡착 · 날씨 파티클(비·눈·폭풍·안개) · 합성 소리(WebAudio, 소리 켜기 버튼)
- 적은 바닥 원으로 1.2초 예고 뒤 터진다. 안에 있으면 체력 1 감소.
- 위쪽 숫자 4개: 처치 · 체력 · 최근 멈춤(ms) · 방금 쓴 이펙트 키(예: `sword-fire`). 하단 "조작·기록 보기"에 최근 이벤트 로그.

## 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 3D 아레나(플레이어·적·카메라·입력). 모든 연출은 `GameFeel.emit` 한 번으로 호출 |
| `game-feel.js` | 연출 시점·크기(멈춤·흔들림·줌·흡착·날씨·소리 큐). 상수표 `GameFeel.CONST` 한 곳 |
| `game-feel-audio.js` | 이펙트 키별 소리 층 합성(외부 음원 없음, `sample` 슬롯으로 교체 가능) |
| `vfx-engine.js` `presets.js` `vfx-gl.js` | 검기·타격 그래픽 엔진(원본 `projects/creative/vfx`를 고치지 않고 복사) |
| `vfx-set.js` | 무기×속성 이펙트 키 표(`VFXSet.weapon`). 이 데모는 키 이름만 쓰고 셰이더 렌더는 쓰지 않는다 |

## 알아 둘 것
- 속성 9종 중 `wind`·`metal`은 그래픽 엔진에 전용 프리셋이 없어 각각 눈보라·신성 프리셋으로 대신 그린다(키와 소리는 속성 그대로).
- 소리는 합성음이며 실제로 귀로 들어 다듬은 것은 아니다. 브라우저 정책상 "소리 켜기"를 눌러야 난다.
- `prefers-reduced-motion`이면 흔들림·줌이 줄어든다.
- 비-숫자·빈 입력 등 경계 처리와 단위 시험은 원본 모듈(`game-feel/test.js`, `test-audio.js`)에 있다.
